建立可重現的 YOLO 訓練/匯出流程

依序完成 4 個步驟。每一步按 Submit 才會解鎖下一步；按 Back 可回到前一步。

重要提醒（依目前步驟顯示）

    Step 1 · Mode

    規則：請先填寫 Task（唯一）並選擇運行模式。若選 SSH，必須填寫 SSH 連線資訊。
    Task 用於保存/區分每次專案紀錄；需唯一。按下 Save 後才會被保存。
    • Generate bundle only：只產生可執行的 bundle zip（下載後你自行在任意機器執行）。
    • Run via SSH：由本網站透過 SSH 連到你的設備執行（需要填 Host/User/認證）。
    • Host：要連線的目標機器（建議填 IP 或可解析的主機名）。
    • Remote dir：遠端放置 bundle 與輸出檔的目錄（建議用絕對路徑）。
    • Python：遠端執行用的 python 指令或完整路徑（例如 conda env 的 python）。
    SSH 設定（選 SSH 才需要）
    Python should be an executable, e.g. python3 or /home/.../miniconda3/envs/ENV/bin/python.
    建議使用 SSH key，並使用權限受限的帳號（避免 root）。

    Step 2 · Dataset(s)（Roboflow）

    規則：資料集目前僅支援 Roboflow。至少需要 1 個 dataset（workspace / project / version）。若要 Hybrid，請新增 ≥2 並為每個 dataset 填寫「類別名稱」。
    • API key：Roboflow 的 API key（無法從 URL 自動推算），請自行貼上。
    • Workspace (slug)：Roboflow Universe/Workspace 的識別字（URL 第一段）。
    • Project (slug)：資料集專案識別字（URL 第二段）。
    • Version：資料集版本號（URL 內的 /dataset/<version>）。
    • Format：下載格式（本系統主要用 YOLOv8/YOLOv11；若選 YOLOv11，下載端會以相容的 YOLOv8 格式取得資料）。
    • Class name：此資料集對應的類別名稱（Hybrid 合併時會以此建立最終 names）。
    • 快速填入：三種方式擇一（Jupyter / Terminal / Raw URL），貼 Roboflow 的 Download Code 或 URL，按 Parse 即可自動填 API key / workspace / project / version / format；API key 會自動遮罩避免明文留在畫面。
    快速填入（貼 Download Code / CLI / Raw URL，自動解析）
    支援：Roboflow(api_key="...")、.workspace("...")、.project("...")、.version(n)、.download("yolov8")。
    支援：roboflow download -f <format> -l <path> <workspace>/<project>/<version> 或包含 URL 的 curl "https://api.roboflow.com/..."。
    支援：REST API URL（含 api_key）或 <workspace>/<project>/<version>（格式不足時不會覆蓋 Dataset 的 Format）。
    三種方式擇一：選好語法類型後貼上，再按 Parse。包含 API key 時，會自動遮罩避免明文留在畫面。
    可新增多個 dataset（Hybrid 需要 ≥2）。

    Step 4 · Train&Export

    規則：本專案僅支援 Detection。請選 YOLOv8/YOLO11 與大小 n/s/m/l/x，並設定超參數。
    • Model family/size：選 YOLOv8/YOLO11 + 尺寸（n/s/m/l/x）。
    • epochs/batch/imgsz/workers：訓練輪數/批次/輸入尺寸/資料載入執行緒數。
    • Device：可填 cpu、單 GPU 0，或多 GPU 0,1,2,3（多 GPU 需機器有對應 GPU）。
    • Optimizer/lr0/patience/close_mosaic：常用訓練設定；建議先用少量 epochs 測通流程。
    • Data balancing：SMOTE-like oversampling（重複取樣）只作用在 train，會輸出平衡前/後的 class 數量圖與 CSV。
    • Balance target：
      • mean：補到各類別平均數（較穩，預設）。
      • max：補到最多類別數（最平衡但資料可能膨脹）。
      • custom：自訂目標（"multiplier" 代表以 max_count×倍率；"count" 代表固定目標數量）。
    • Merge（選填）：當未勾選 Hybrid merge 時，會出現依 Class name 分組的 datasets。你可選擇要用哪些 datasets 進入訓練；勾選後請按 Select/Merge 才會生效。
    Targets（Train & Export）
    勾選 Target 後，右側「▾」可展開細項。每個 Target 的細項都必須按下 Save 才算完成。
    Hybrid 與其他 Target 互斥：可同時勾選（不會自動取消），但按下 Step4 Submit 時會檢查互斥並提示你修正。

    Step 6 · Review & Run

    規則：請確認所有選擇。按 Save 後才會保存專案；按 Submit 後會依 mode 產生 bundle 或 SSH 執行。
    提醒：此專案尚未儲存，請按下 Save 以保存。
    • 此頁會整理你前面所有選擇，請先確認無誤。
    • 按 Submit 後才會真正執行（或產生 bundle / 或 SSH 執行）。
    • 執行完成後可下載 artifacts（results.png、曲線圖、log）。
